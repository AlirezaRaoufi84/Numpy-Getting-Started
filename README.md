My NumPy Learning Path
This repo is just my personal notes and exercises as I learn NumPy from scratch, with the goal of getting comfortable enough to use it for ML/AI later. It's not a tutorial, not a course, and definitely not a replacement for proper documentation or structured courses. I'm just tracking my progress in public.

What's in here
A few notebooks I'm working through, roughly in this order:

Basics — arrays vs lists, shapes, dtypes

Creating arrays — zeros, ones, arange, random

Indexing & slicing — including boolean masks

Reshaping — reshape, transpose, flattening

Math & stats — mean, std, axis stuff

Broadcasting — the part I keep getting wrong

Linear algebra — dot products, matrix multiplication

Each notebook is mostly me typing things out, breaking them, and writing down what I figured out.
